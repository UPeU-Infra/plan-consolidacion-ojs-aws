## Contexto

La UPeU opera 5 revistas científicas en instancias `c6i.2xlarge` con CPU promedio de **0.15%**, generando costos superiores a **USD 1,455/mes**. Este repositorio documenta el plan de consolidación y optimización hacia instancias `t3.large`, reduciendo el costo a **~USD 452/mes**.
